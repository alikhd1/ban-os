معماری کامل سیستم‌عامل Ban OS

محور اول: ساختار سیستم‌عامل و زیرساخت Ban OS

این سند، تمام فازهای بخش سیستم‌عامل Ban OS را از پایه تا انتشار Production پوشش می‌دهد. تمرکز آن روی معماری، اجزای اصلی، مسئولیت هر فاز و خروجی مورد انتظار است؛ بنابراین در هر فاز مشخص می‌شود چه چیزی باید ساخته شود، اما جزئیات اجرایی هر فاز را می‌توان جداگانه باز کرد.

نمای کلی معماری

Ban OS یک سیستم‌عامل اختصاصی برای پایانه‌های فروش (POS) است که بر پایه Debian ساخته می‌شود و نرم‌افزار Adad را به‌عنوان برنامه اصلی اجرا می‌کند.

معماری پیشنهادی:

Ban OS User Experience

Adad POS · Ban Center · Maintenance Mode

Ban OS Application & Control Layer

Adad Launcher · Ban Agent · Hardware Services · Update Manager

Linux Service Layer

systemd · NetworkManager · CUPS · journald · udev · RustDesk

Debian Linux Base

Kernel · Drivers · Filesystem · Security · Package Management

POS Hardware

Touchscreen · Printer · Scanner · Cash Drawer · Display · Network
