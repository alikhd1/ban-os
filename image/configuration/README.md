# image/configuration/

Files copied into the root filesystem of every image (staged into
`image/live-build/config/includes.chroot_after_packages/`). The variant's and the profile's
`configuration/` folders are copied on top. `/etc/ban/release` is generated by the build.

Stage 1: `/etc/hostname`, `/etc/hosts`, `/etc/locale.gen`, `/etc/timezone`,
`/etc/default/keyboard`, journald and timesyncd drop-ins, `/etc/logrotate.d/adad`,
`/usr/lib/tmpfiles.d/ban.conf` and the boot helpers in `/opt/ban/boot/`. See
`docs/architecture/layout.md`.

**Filled in:** Stage 1 (step 1.3) onward.
