# image/live-build/

The live-build working directory. `make build` runs `lb clean`, `lb config` and `lb build` here.

- `auto/config`: the `lb config` options of Ban OS (trixie, amd64, UEFI, local apt-cacher-ng mirror).
- `auto/clean`: `lb clean` plus removal of the files generated by `auto/config`.
- `config/`: live-build configuration. `config/package-lists/` is **generated** by
  `image/scripts/build-image.sh` from `image/packages/`,
  `image/variants/<variant>/package-lists/` and `config/<profile>/package-lists/`;
  do not edit it. Everything live-build generates here is git-ignored.

**Filled in:** Stage 0 (minimal, nearly empty image); Stage 1 (step 1.1) adds `includes.chroot`,
`includes.binary`, `hooks` and `bootloaders`.
