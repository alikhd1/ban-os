# apps/tech-tools/

`ban-tech-tools` meta-package (terminal, editor, file manager, htop, psql). Not part of the image; installed from Ban Center.

The `server` variant gets `ban-tech-tools-cli` (text tools only: nano, htop, psql, tcpdump,
nmap), installed from `ban-console`.
