# console/

`ban-console`, the text-mode technician panel of the `server` variant (and the Recovery UI of
both variants). A client of Ban Agent like Ban Center, over the same socket and the same
`crates/ban-api-types` contract; it performs nothing privileged itself.

**Filled in:** Stage 5 (skeleton); screens added in Stages 6, 7, 9, 10, 11 and 12.
